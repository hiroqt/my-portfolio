# Codebase Map

- [app/(portfolio)](../app/(portfolio)) holds the home page (Overview: profile through Languages & tools) and one page per sidebar link (experience, projects, skills, stack, certifications, services, contact). Its layout wraps them in [PortfolioShell.tsx](../components/PortfolioShell.tsx), the sidebar (a drawer below 1024px) and footer; [lib/portfolio/sections.ts](../lib/portfolio/sections.ts) maps old `/#section` links and assistant section ids to those pages.
- [components/home](../components/home) holds the Overview's profile, stats, and recognition blocks; [components/sections](../components/sections) holds the lists: experience, projects, skills, stack, and certifications. They share [List.module.css](../components/sections/List.module.css), and [ExpandableList.tsx](../components/sections/ExpandableList.tsx) adds the "+N more" reveal.
- [projects.ts](../lib/data/projects.ts) holds project records used by the portfolio and assistant (only records with a `showcase` entry appear, in order, in the home page project list); [lib/rag](../lib/rag) contains the assistant's retrieval knowledge.
- [PortfolioShell.module.css](../components/PortfolioShell.module.css) and [List.module.css](../components/sections/List.module.css) style these pages; [app/globals.css](../app/globals.css) defines shared theme tokens.
- [blog.ts](../lib/data/blog.ts) holds blog posts as typed blocks; [app/blog](../app/blog) renders the index and each post with components from [components/blog](../components/blog), which turn every URL in post text into a link.
- [app/typing](../app/typing) is the typing playground page, linked from the home page sidebar; the game lives in [components/modules/typing](../components/modules/typing).
- [lib/blog/views.ts](../lib/blog/views.ts) counts blog post views in Upstash Redis (once per visitor per post per day; local and preview counts are kept apart from production) behind the [views API route](../app/api/blog/views/[slug]/route.ts).
